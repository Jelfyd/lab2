# Космос поруч

Це мій навчальний проєкт на Symfony - невеликий каталог планет, супутників і космічних апаратів.На головній є пошук і фільтр за категорією, а ще щодня виділяється один об’єкт.У кожного запису є окрема сторінка з описом і цікавим фактом.

Категорії та об’єкти зберігаються в SQLite через Doctrine.Один об’єкт належить до категорії.Керувати записами й категоріями можна в EasyAdmin.

## Запуск

Потрібні PHP 8.2 або новіший із розширеннями `ctype`, `iconv`, `mbstring` і `pdo_sqlite`, Composer та Symfony CLI.

У терміналі перейдіть у папку проєкту й виконайте:

```bash
composer install
php bin/console doctrine:migrations:migrate
php bin/console app:admin:create
symfony serve
```

Під час створення адміністратора введіть email і пароль.Пароль вводиться приховано й не зберігається в коді. Після запуску сайт буде доступний за адресою, яку покаже `symfony serve`; сторінка входу — `/login`, адмін-панель — `/admin`.

База SQLite створюється у `var/data.db`.Міграції створюють таблиці та додають початкові записи каталогу.

## Що є на сайті

- `/` — каталог, пошук і фільтр за категорією;
- `/space/1` — сторінка об’єкта з ID `1`;
- `/api/space` — список об’єктів у JSON;
- `/api/space/1` — один об’єкт у JSON;
- `/admin` — керування об’єктами й категоріями після входу.

У папці `client` є простий Python-клієнт для API. Наприклад:

```bash
python client/client.py
python client/client.py --id 1
```
